# NebulaGram

**Ваш Telegram. Ваш стиль. Ваше подключение.**

Неофициальный клиент Telegram для Android и iOS со встроенным NebulaLink,
плавающими панелями и гибкой настройкой интерфейса.

NebulaGram сохраняет привычные чаты, каналы, папки и аккаунты Telegram,
добавляя собственное оформление и управление подключением прямо в приложении.
NebulaLink подключает мессенджер через выбранный вами сервер: отдельное
VPN-приложение для этого не требуется.

## Возможности

| | Что можно настроить |
| :--- | :--- |
| **Подключение** | Подписки Remnawave, импорт ссылок и конфигураций Xray, выбор сервера и проверка задержки. |
| **Оформление** | Цвета Material You на Android 12+, плавающие шапки чатов, баннеры профилей и скруглённые карточки. |
| **Поле сообщения** | Отдельные кнопки вложений и отправки, оформление в стиле iOS, настройки камеры и выбора отправителя. |
| **Навигация** | Порядок и видимость нижних вкладок, подписи, компактная панель, меню быстрых действий и действия по удержанию. |
| **Папки и топики** | Название активной папки в шапке с анимацией, настройки счётчиков и плавающий заголовок темы. |
| **Настройки оформления** | Четыре стиля тумблеров с превью, счётчик чатов на кнопке назад, блики стекла, отдельные разделы папок, сообщений и профиля. |
| **Меню сообщения** | Опциональное размытие фона и расположение меню под выделенным сообщением. |
| **Детали** | Собственные иконки в стиле iOS, скрытый номер в шапке настроек, отображение секунд в сообщениях. |

Настройки доступны через **Настройки → Настройки NebulaGram**.
Превью шапки и поля ввода используют текущие обои; дополнительные параметры
собраны в сворачиваемые разделы.

## Скачать

Сборки для Android и iOS будут публиковаться в [Releases](https://github.com/BBGGVP5/NebulaGram/releases).
Откройте нужную версию и выберите файл в разделе **Assets**.

| Платформа | Файл | Установка |
| :--- | :--- | :--- |
| **Android** | `.apk` | Скачайте APK и откройте его на устройстве. |
| **iOS** | Неподписанный `.ipa` | Скачайте IPA и подпишите его выбранным способом перед установкой. |

На Android при запросе системы разрешите установку из выбранного источника.
NebulaGram устанавливается рядом с официальным Telegram: у Android-приложения
отдельный пакет `app.nebulagram.messenger`.

Неподписанный IPA не устанавливается простым открытием файла: для установки
на iPhone или iPad нужна подпись.

## Подключить NebulaLink

1. Откройте **Настройки → Настройки NebulaGram → NebulaLink**.
2. Добавьте ссылку на подписку или импортируйте конфигурацию своего сервера.
3. Выберите сервер, при необходимости проверьте задержку и включите подключение.

Поддержка параметров подключения зависит от встроенного ядра и конфигурации
сервера. В текущую Android-сборку включён **Xray-core**.

Данные подписок и серверов сохраняются в приватном каталоге приложения.
При обновлении подписки приложение обращается к её провайдеру, а при подключении —
к выбранному серверу. Серверы проекта для туннеля не предоставляются: вы используете
свой сервер или сервис выбранного провайдера. Сетевые функции самого Telegram
продолжают работать в рамках его инфраструктуры.

## Обратная связь

Ошибки и предложения — в [Issues](https://github.com/BBGGVP5/NebulaGram/issues).
Для ошибки укажите версию приложения, модель устройства, версию Android или iOS
и шаги воспроизведения. Для проблем оформления полезен скриншот с выбранными
настройками темы. Удалите из вложений ключи серверов, ссылки на подписки и личные данные.
