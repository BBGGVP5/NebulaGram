# Инструменты сообщений Android

В меню сообщения появился пункт **«Инструменты сообщения»**. Общий экран
доступен через **Настройки NebulaGram → Инструменты текста**, задачи — через
**Настройки NebulaGram → Список дел**.

## Что реализовано

- Перевод и краткое содержание выбранного текста через настроенного провайдера
  Nebula AI. Результат можно скопировать; сообщения в чат автоматически не отправляются.
- Автоперевод видимых текстовых сообщений, включаемый отдельно для каждого чата.
  Используется одна очередь максимум на 20 ожидающих запросов; повторные запросы
  объединяются, результаты кешируются в памяти. При выходе из чата запросы отменяются.
  Защищённые и исчезающие сообщения не отправляются на перевод.
- Озвучивание текста установленным движком Android, с остановкой при выходе.
- Распознавание скачанного голосового или видео через Gemini, до 14 МБ за запрос.
  Нужны собственные API-ключ и модель с поддержкой аудио. Другие провайдеры для
  распознавания пока не подключены. Длительность в 15 минут не гарантируется:
  ограничение этой реализации относится к размеру файла.
- Локальные задачи: название, описание, выполнение, редактирование, удаление,
  напоминания. Данные и идентификаторы напоминаний разделены по Telegram user ID.
  Android может задерживать неточные напоминания при энергосбережении; требуется
  разрешение уведомлений. Задачи не синхронизируются с другими устройствами.
- Фильтр входящих сообщений по буквальному совпадению слов/фраз. Содержимое
  заменяется заглушкой и раскрывается нажатием. Сообщения не удаляются;
  рекламные сообщения исключены из фильтра. Это фильтр отображения, не защита паролем.
- Исправлен оставшийся Java-лимит 3/5 аккаунтов: он теперь соответствует уже
  существующим десяти слотам аккаунтов и дополнительному служебному native-слоту.
- Долгое нажатие на строку настроек NebulaGram копирует ссылку на раздел/настройку.
  Ссылка только открывает экран и не меняет значение настройки.

Перевод, сводки и распознавание передают выбранные данные настроенному провайдеру;
автоперевод требует отдельного включения. Ключи не включаются в ссылки на настройки.

## Что ещё не реализовано из предоставленного списка iMe

Отдельные пароли на чаты и автоматическая облачная синхронизация настроек остаются
открытыми задачами. Существующий импорт/экспорт файла не является облачной
синхронизацией. Платный приоритет поддержки не предоставляется этой реализацией.
Новые инструменты этой поставки относятся к Android; перенос на iOS не выполнен.

## Проверка изменений

Проверены Java-компиляция, применение серии патчей к закреплённому Telegram,
протоколы провайдеров на HTTPS-заглушках, отмена/лимит аудиозапроса, изоляция задач,
замена и отмена напоминаний, сохранность повреждённого файла, Java/native-слоты,
логика меню и нижней панели. Реальные ответы провайдеров с пользовательскими
ключами и отрисовка новой сборки на телефоне не проверялись.
