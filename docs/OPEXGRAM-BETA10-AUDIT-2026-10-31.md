# Opexgram 13.1.1 beta 10: предварительная сверка

Запрос: дополнить NebulaGram функциями из присланного списка. Приоритетом
пользователь уточнил дефект загрузки: истории сначала появляются на заголовке,
затем смещаются. Исправление этого дефекта — патч 0250, отдельный план
`superpowers/plans/2026-10-31-home-stories-first-layout.md`.

Это сверка исходников NebulaGram, не аудит исходников Opexgram и не проверка
полного совпадения поведения на устройстве.

| Пункт | Найдено в NebulaGram | Что ещё уточнить/сделать |
|---|---|---|
| Telegram 13.1 | Закреплён Telegram 13.1.1 | Отдельно проверить новый QR и перенос подарков; версия базы сама по себе не доказывает доступность всех серверных функций |
| Меню iOS / фокус | Имеются меню, фокус и проверки; последний фикс закрытия меню — `5eb0f9c` | Сопоставить конкретное желаемое поведение, не заменять исправленное меню целиком |
| Material 3 Back | Есть `predictive_back` и нативные hooks патча 0152 | Визуальное совпадение с Opexgram не проверено |
| Сжатие у краёв | Патч 0247 подключает `NebulaEdgeCompression` к списку чатов | Присланный пункт включает ещё сообщения; эту часть отдельно проверить |
| Шрифты | `NebulaFont`: переключатель Telegram/системный, патч 0248 | Импорта пользовательского файла в этом компоненте нет |
| Блики стекла | `NebulaAppearance.glassHighlights`, ключ `glass_highlights` | Уже есть настройка; совпадение эффекта не проверялось |
| Локальная расшифровка | `NebulaLocalAudioSettingsFragment`, режим Android и отдельный Nano | Доступность зависит от устройства и модели; наличие настройки не гарантирует работу на каждом телефоне |
| AI: объём истории перед запросом | Есть сводка отдельного сообщения (`NebulaAiReplacements`) | Это не выбор числа сообщений для поиска/сводки чата; требуется отдельная реализация/дальнейший поиск |
| Карточки списка | Патч 0244 | Шапку, поиск и карточки сравнивать отдельно |
| Камера кружков | `NebulaRoundCamera`, панели выбора и CameraPolicy | Требуется сравнение набора режимов, повторно не добавлять существующий выбор |

Пока не подтверждены/не исследованы полностью: очередь медленного режима,
неограниченное выделение, массовое удаление своих сообщений, запасная оценка даты
регистрации, импорт шрифтов, ambient-подсветка медиа, экспорт чата, бот-настройки,
Monet-палитры, новые цитаты и анимации текста. Нельзя считать отсутствие результата
одного поиска доказательством отсутствия функции.

Исправления из чужого changelog (форумы после поиска, сброс настроек, повторная
покупка подарка, пустой AI-ответ, высота видео) нужно сначала воспроизвести или
найти соответствующий дефект в нашей базе. Они пока не объявлены исправленными.

Открыт вопрос пользователю о приоритетной группе дополнений: оформление,
удобство чатов или AI. После ответа составить отдельный план реализации выбранных
функций; весь список не считать уже согласованным техническим объёмом.
