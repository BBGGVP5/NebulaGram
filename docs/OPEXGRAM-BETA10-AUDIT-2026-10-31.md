# Opexgram 13.1.1 beta 10: сверка и реализация Android

Пользователь 31 октября поручил сделать недостающие функции. Реализация самостоятельная поверх Telegram 13.1.1; исходники Opexgram beta 10 не найдены в доступных публичных репозиториях. Дизайн сохраняет стиль NebulaGram.

| Пункт списка | Состояние / реализация |
|---|---|
| Telegram 13.1: QR | В базе есть `QrShareActivity`, вход из `SettingsActivity` |
| Коллекционные подарки и кошелёк | В базе `Stars/StarGiftSheet` и `Wallet/GramWallet`: перенос и отображение подарка на карточке; серверная доступность отдельно |
| iOS-меню, фокус | Уже есть `NebulaMenuFocus`, `NebulaMenuBubble`, `NebulaMessageMenuFragment`, последняя коррекция закрытия `5eb0f9c` |
| Material Back | Уже есть опциональный `predictive_back` и native hook 0152; системная поддержка зависит от Android |
| Сжатие чатов/сообщений | Чаты — 0247; добавлены отдельные сообщения Android 13+ — 0253. Альбомы и активные item-анимации не преобразуются |
| Медленный режим | Добавлена очередь обычного текста через отложенные сообщения — 0252; интервалы сохраняются для аккаунта/чата, отмена в нативном экране |
| Локальная расшифровка | Уже есть Android recognizer и отдельный Nano-режим; нужен совместимый сервис/модель, не работает гарантированно на любом устройстве |
| Свой шрифт | Добавлен импорт TTF/OTF до 8 МБ, предпросмотр, выбор и возврат Telegram/системного шрифта |
| Material 3 шапка с blur | Добавлен режим 0256: обычное размытие без преломления, скруглённый низ, Android 12+ |
| Новый поиск / карточки чатов | Поиск и папки уже интегрированы; карточки — 0244. Новые настройки включены в индекс поиска |
| Блики стекла | Уже есть `glass_highlights` |
| Камера кружков | Уже есть выбор камеры/модуля, `NebulaRoundCamera`, CameraPolicy и панели управления |
| Объём истории для ИИ | Добавлен выбор 50/100/250/500/1000 перед поиском/сводкой. Показано фактически переданное число сообщений; ограничение текста 120000 символов |
| Выделение без 100 | Добавлено opt-in снятие UI-лимита в обычном чате. Жалобы и серверные лимиты действий сохранены |
| Удаление своих сообщений | Новый экран инструментов: поиск в выбранном объёме, предварительное количество, явное подтверждение, проверка владельца/прав, native batches до 100 |
| Оценка регистрации | Telegram month → локальный кэш/диапазон → граница по ранней переписке. Оценки явно помечены; при недостатке данных отображается отсутствие оценки |
| Компактные настройки | Уже разбиты на короткие страницы `NebulaSettingsHubFragment`, дополнительные блоки сворачиваются |
| Анимация текста | Добавлено опциональное появление/обновление текста за 160 мс, с учётом системного уменьшения анимаций |
| Цитаты | Сохранён native QuoteSpan и панель форматирования NebulaGram; фраза «переделаны чутьЧуть» не задаёт конкретного нового поведения для копирования |
| Ambient медиа | Добавлена цветная подсветка фона просмотрщика. Обновление по TextureView до 2 раз/с; для SurfaceView/недоступных кадров используется превью либо эффект отсутствует |
| Действия свайпом | Уже есть `NebulaSwipeSettingsFragment`, список/порядок действий и native визуальные hooks |
| Экспорт чата | Новый UI: JSON выбранного объёма и потоковый TXT всей доступной истории через системное сохранение; текст, подписи, даты и ID, без скачивания медиа |
| Настройки ботов | Новый список управляемых ботов; профиль/переводы и звёзды. При активном аккаунте бота — меню, права групп/каналов и просмотр бизнес-подключения по ID. Новый способ авторизации бот-токеном не добавлялся |
| Папки | Уже есть свайпы, настройки панели и синхронная анимация ширины заголовка/историй |
| Monet | Добавлен выбор основной, мягкой, дополнительной и нейтральной системной палитры, действует при Material You |
| Видео на всю высоту | База содержит `getVideoFitHeight`; без воспроизведения чужого бага новый фикс не объявлен |
| Форумы после поиска | База использует `TopicsFragment.onSearchCollapse → animateToSearchView(false)`; конкретный дефект не воспроизведён |
| Сброс | Добавлен подтверждаемый сброс переносимых настроек с обновлением шрифтов/иконок/темы; аккаунты, ключи ИИ и scheduled messages не удаляются |
| Двойная покупка подарка | В базе есть защита `button.isLoading` перед покупкой. Специфический повтор scheduled gift не воспроизведён; платежная логика не менялась |
| Пустой ответ ИИ | Ужесточена проверка в `NebulaAiReplacements`: null и строка из пробелов считаются ошибкой |

## Ограничения приёмки

Кодовые проверки не являются визуальной проверкой телефона или живой проверкой bot-only RPC. Пункты чужого changelog без описания воспроизведения не считаются автоматически дефектами NebulaGram. Новая очередь рассчитана на обычный текст; медиа, пересылки, платные сообщения и rich editor используют прежнее поведение.

Объём технических проверок, коммиты и результаты CI фиксируются в `docs/superpowers/plans/2026-10-31-opexgram-additions.md`.
