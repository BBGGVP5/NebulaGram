# Паки значков Android

Открытие: Настройки Nebula → Дизайн → Паки значков. Выберите встроенный вариант или импортируйте файл через системный выбор документов. Импорт сначала проверяет и полностью декодирует изображения; применить пак нужно отдельной кнопкой. Есть предпросмотр, экспорт и удаление.

`.icons` — ZIP с `metadata.json` в корне:

```json
{
  "schemaVersion": 1,
  "packName": "My Outline",
  "packId": "my-outline",
  "author": "Author",
  "version": "1.0",
  "icons": {
    "msg_search": "icons/search.svg",
    "msg_settings": "icons/settings.png",
    "msg_delete": "icons/delete.webp"
  }
}
```

Ключи `icons` — имена Android drawable-ресурсов Telegram без расширения. Подмена действует через общий слой `NebulaIconResources`, поэтому один ресурс меняется в чате, списке, меню и настройках, где он используется. Если ресурса нет в карте, остаётся оригинал; картинки профилей, эмодзи и программно рисуемые элементы не являются drawable-значками и этим форматом не заменяются.

Допускаются SVG с поддерживаемыми Telegram простыми векторными фигурами, PNG и WebP. Для SVG запрещены сценарии, внешние ссылки, DTD, изображения и внешние объекты. Размер растра — до 1024×1024; отрисовка использует отдельные Drawable с сохранением штатных размеров и окраски темы. Большие изображения уменьшаются до 96×96 для кеша.

Ограничения: 512 сопоставлений, 2048 ZIP-элементов, 256 КБ на файл, 128 КБ метаданных, 32 МБ распакованных данных и 16 МБ входного архива; до 40 установленных паков. Абсолютные пути, выход из архива и повторяющиеся пути запрещены. Некорректный пак не заменяет установленный. Кеш принадлежит выбранному паку; после применения некоторые уже созданные панели нужно открыть заново.

Встроенный **Remix Outline**: 51 SVG и 75 сопоставлений. Исходные изображения взяты из [Remix Icon v4.6.0](https://github.com/Remix-Design/RemixIcon/tree/v4.6.0), commit `8bc436bdd329cf342958d8effdd078bfa74354c6`, по лицензии Apache 2.0. Текст лицензии и сведения об источнике находятся в `platform/android/licenses/`. Новейшая версия библиотеки не используется как лицензионная замена этому закреплённому выпуску.

Метаданные совместимы с изученным форматом `.icons` exteraGram. Это не обещание поддержки всех SVG-возможностей сторонних паков: файлы проходят ограничения и декодирование выше.
