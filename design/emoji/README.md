# Telegram custom emoji

Selected exports of the generated badge artwork, ready for upload:

- `supporter-100.png`: NebulaGram logo, transparent 100 × 100 PNG.
- `mira-six-ray-100.png`: Mira six-ray star, transparent 100 × 100 PNG.

Use the official https://t.me/Stickers bot or mini app. Start `/newemojipack`, choose static emoji, name the set, send each PNG as a file, associate an ordinary emoji, then use `/publish` and follow the remaining prompts. Do not send as a compressed photo.

Requirements: https://core.telegram.org/stickers#static-stickers-and-emoji

These files have not been uploaded or published automatically. Creating a set is available to everyone; normal use of custom emoji sets requires Telegram Premium.
